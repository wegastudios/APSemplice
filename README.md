# APSemplice (APS Semplice)

Plugin **WordPress** per un'associazione di promozione sociale (APS): soci e ospiti, corsi ed eventi, prima nota, conti e fondi, area riservata sul sito.

- Codice del plugin: [`wordpress/apsemplice/`](wordpress/apsemplice/)
- Documentazione: [docs/PLUGIN_WORDPRESS.md](docs/PLUGIN_WORDPRESS.md) (funzioni), [docs/AREA_RISERVATA.md](docs/AREA_RISERVATA.md) (shortcode e contenuti riservati), [docs/LICENZE.md](docs/LICENZE.md) (licenze), [docs/VISIONE_E_STRUTTURA.md](docs/VISIONE_E_STRUTTURA.md) (visione)
- Lo zip installabile viene prodotto dalla CI (`.github/workflows/plugin.yml`): test unitari su PHP 7.4/8.1/8.3, smoke test su un WordPress reale e pacchetto del plugin.

La vecchia app Android è stata rimossa dal repository (resta nella cronologia di git).
